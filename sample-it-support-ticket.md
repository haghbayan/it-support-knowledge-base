# Sample IT Support Ticket

## Ticket Information

- Ticket ID: IT-001
- Category: Network Connectivity
- Priority: Medium
- Status: Resolved
- ## Problem Description

The user reported that the computer could not connect to the internet.

## Troubleshooting Performed

1. Checked the Wi-Fi connection.
2. Verified that other devices could connect to the network.
3. Restarted the network adapter.
4. Tested the internet connection again.
## Resolution

The internet connection was restored after the network adapter was restarted.

## Prevention and Follow-up

If the problem occurs again, check the network adapter and review the network settings.
